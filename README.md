# FroFit — Fitness Coaching Platform (Website Prototype)

**Founder & developer:** Mihnea Fronie

## About

FroFit is a personalized fitness and nutrition coaching startup I'm building. This repository holds the front-end prototype of the FroFit marketing website — the public-facing site presenting the brand, the subscription plans and the coaching offer, as the first step of the project.

## Pages

- **Home** (`frofit.html`) — landing page introducing FroFit
- **Subscription Plans** (`subscriptionplans.html`) — three pricing tiers (Starter, Transformation, Elite), each unlocking a different level of personalized training, nutrition guidance and coach support
- **Articles** (`articles.html`) — fitness & nutrition content (common training myths, progressive overload, recovery nutrition)
- **About Us** (`aboutus.html`) — FroFit's mission and the founder's story
- **Contact** (`contact.html`) — contact details and a contact form

## What each subscription includes

- Personalized training plans, tailored to the client's goal (muscle gain, fat loss, performance, general health)
- Custom nutrition plans
- Progress check-ins (monthly, weekly or 24/7 direct support, depending on the tier)
- 1-on-1 coaching calls (higher tiers)

## Tech stack

- HTML5 & CSS3 — custom, no framework
- Google Fonts (Archivo Black, Arimo)
- Boxicons (icon library, via CDN)
- Static front-end only — the contact form is not yet wired to a backend

## Status

🚧 Early-stage prototype. This repo currently covers the front-end presentation site. The actual coaching platform (client accounts, plan builder, progress-monitoring dashboard) hasn't been built yet.

## Why I'm building this

I've been into fitness training and nutrition since I was 15, and FroFit is where I get to combine that with software development — starting from a static presentation site and building toward an actual product, one step at a time.
